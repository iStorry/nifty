# tree-sitter-nifty

Tree-sitter grammar for Nifty, used by the Zed extension in [`../zed`](../zed). It
mirrors the parser in `crates/nifty-syntax`: line breaks end statements, so they are
tokens and appear only where the language allows an expression to continue.

```bash
npm install
npm run generate
npm test
```

`src/` is generated by `npm run generate`; commit it with any change to `grammar.js`,
since Zed builds the grammar from `src/parser.c`.
